MBA Hub Recovery

Permanent install, reinstall and sharing page for Monterey Bay Aquarium Hub users.

Open MBA Hub

If the Hub works normally, use the button above. Reinstall only when the installed Hub remains stuck after refresh/cache troubleshooting.

Install / Reinstall on iPhone
  1. Open this Recovery page in Safari.
  2. Before removing the old MBA Hub: tap Share → Add Bookmark and save this Recovery page. You may also add the Recovery page to your Home Screen as a separate emergency icon.
  3. Leave this Recovery page open in Safari.
  4. If replacing a stuck MBA Hub, return to the Home Screen and remove only the old MBA Hub Home Screen icon.
  5. Return to this Recovery page in Safari. If it is no longer open, reopen it from your bookmark.
  6. Tap Open MBA Hub above and confirm the current Hub loads.
  7. In Safari tap Share → Add to Home Screen → Add.
  8. Open the new MBA Hub icon and verify current content.

Important: Keep MBA Hub Recovery bookmarked or installed separately. Do not remove your recovery path before deleting a stuck Hub.

Install / Reinstall on a computer
  1. Open this Recovery page in your browser.
  2. Use Open MBA Hub.
  3. Use your browser's Install App / Create Shortcut / Add to desktop option when available.
  4. If replacing an old installed Hub, remove the old shortcut/app first if it remains stuck.
Hub not updating
  1. Try the Hub's Clear Cache control and reload.
  2. If the old Hub still persists, open this Recovery page in Safari.
  3. Bookmark this Recovery page before removing the old Hub.
  4. Remove only the old MBA Hub Home Screen/Desktop installation.
  5. Return to the Recovery page and reinstall using the steps above.
