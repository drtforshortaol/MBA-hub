MBA Hub Recovery

Permanent install, reinstall and sharing page for Monterey Bay Aquarium Hub users.

Open MBA Hub

If the Hub works normally, use the button above. Reinstall only when the installed Hub remains stuck after refresh/cache troubleshooting.

Install / Reinstall on iPhone
  1. Open this Recovery page in Safari.
  2. If replacing a stuck MBA Hub, remove the old MBA Hub Home Screen icon.
  3. Tap Open MBA Hub above and confirm the current Hub loads.
  4. In Safari tap Share → Add to Home Screen → Add.
  5. Open the new MBA Hub icon and verify current content.

Keep MBA Hub Recovery installed or bookmarked so these instructions remain available if the main Hub is removed.

Install / Reinstall on a computer
  1. Open this Recovery page in your browser.
  2. Use Open MBA Hub.
  3. Use your browser's Install App / Create Shortcut / Add to desktop option when available.
  4. If replacing an old installed Hub, remove the old shortcut/app first if it remains stuck.
Hub not updating
  1. Try the Hub's Clear Cache control and reload.
  2. If the old Hub still persists, return to this Recovery page.
  3. Remove the old MBA Hub Home Screen/Desktop installation and reinstall using the steps above.
