Install MBA Hub

Windows / PC

Best method: install from Chrome.

  1. Open Chrome.
  2. Go to https://drtforshortaol.github.io/MBA-hub/.
  3. Use Chrome's Install app option.
  4. Choose Install.

iPhone

  1. Open Safari.
  2. Go to https://drtforshortaol.github.io/MBA-hub/.
  3. Tap Share.
  4. Tap Add to Home Screen.
  5. Rename it MBA Hub 2.2.2.
  6. Tap Add.

Android

  1. Open Chrome.
  2. Go to the MBA Hub URL.
  3. Tap the three-dot menu.
  4. Tap Add to Home screen or Install app.

After Installing

Test Install, Help, Clear Cache, search, app opening, and Return to Hub.

If the Installed Version Looks Old

First tap Clear Cache and reload. If the installed Hub is still stuck, remove the old Home Screen/Desktop Hub and reinstall it from the permanent Recovery page.

Open MBA Hub Recovery / Reinstall

Share or Reinstall

The Recovery page contains two QR codes: Install MBA Hub opens the Hub directly for a new user, and Recovery / Help opens the permanent reinstall instructions.

Keep the Recovery page bookmarked or installed separately so reinstall instructions remain available even if MBA Hub is deleted.

Help

Refresh Hub

  1. Tap Clear Cache.
  2. Let the Hub reload.
  3. Confirm the newest content appears.

iPhone Safari Cache

If necessary, clear the site's Safari website data and reopen the Hub.

Broken App Link

Apps belong in apps/app-folder-name/ and use ../../index.html to return to the Hub.

Tags and Cross-Links

Tags filter Hub search. Related apps may come from the registry, Hub links, or shared tags.

Hub Registry Safety

Root Hub data uses hub-registry.js, hub-tags.js, hub-links.js, and supplemental modular additions.
