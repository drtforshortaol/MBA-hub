Install MBA Hub

Windows / PC

Best method: install from Chrome.

  1. Open Chrome.
  2. Go to https://drtforshortaol.github.io/MBA-hub/.
  3. Use Chrome's Install app option.
  4. Choose Install.

iPhone

  1. Open Safari.
  2. Go to https://drtforshortaol.github.io/MBA-hub/.
  3. Tap Share.
  4. Tap Add to Home Screen.
  5. Rename it MBA Hub 2.2.15.
  6. Tap Add.

Android

  1. Open Chrome.
  2. Go to the MBA Hub URL.
  3. Tap the three-dot menu.
  4. Tap Add to Home screen or Install app.

After Installing

Test Install, Help, Clear Cache, search, app opening, and Return to Hub.

If the Installed Version Looks Old

First tap Clear Cache and reload. If the installed Hub is still stuck, open the permanent Recovery page in Safari and bookmark it before removing the old MBA Hub. Then remove only the old Hub icon, return to Recovery, and reinstall.

Help

Refresh / Update Hub

  1. Tap Clear Cache.
  2. Let the Hub reload.
  3. Confirm the newest content appears.

Routine content updates should normally use this method and should not require reinstalling the Hub.

If the Hub Is Still Old or Stuck

  1. Open the Install button at the top of the Hub.
  2. Open the permanent Recovery / Reinstall page in Safari.
  3. Bookmark the Recovery page before removing the old Hub.
  4. If necessary, remove only the old MBA Hub Home Screen/Desktop installation.
  5. Return to Recovery and reinstall the Hub.

Open MBA Hub Recovery / Reinstall

Install or Share MBA Hub

Tap Install at the top of the Hub. The Install panel contains a QR code that opens MBA Hub directly for another user, plus iPhone, PC and Android installation instructions.

Recovery QR Code

The Install panel also contains a separate Recovery QR code. A troubled user can scan it to reach the permanent Recovery page even if their main MBA Hub has been removed.

Keep a Recovery Path

Keep the Recovery page bookmarked or installed separately on a Home Screen/Desktop. This preserves the reinstall instructions if the main MBA Hub must be deleted.

iPhone Safari Cache

If Clear Cache does not solve the problem, Safari website data may also need to be cleared before reopening or reinstalling the Hub.

Broken App Link

Apps belong in apps/app-folder-name/ and use ../../index.html to return to the Hub.

Tags and Cross-Links

Tags filter Hub search. Related apps may come from the registry, Hub links, or shared tags.
